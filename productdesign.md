Crée un site web complet, moderne et premium en **React + TypeScript**, pour un prêtre spirituel / guide spirituel appelé **« Grand Maître Visionnaire »**.

## 1. Objectif du site

Le site doit présenter l'univers, les services, les produits et les témoignages du Grand Maître Visionnaire, tout en permettant aux visiteurs de prendre facilement contact.

L'expérience doit transmettre :

* spiritualité
* confiance
* sagesse
* élégance
* mystère
* sérénité
* professionnalisme
* proximité humaine

Le site doit avoir un rendu **haut de gamme**, comparable à un site de marque premium, avec une direction artistique originale et soignée.

Le design doit éviter les clichés d'un site ésotérique amateur. Privilégier une esthétique **luxueuse, contemporaine, minimaliste et spirituelle**.

# 3. Direction artistique

## Direction artistique

Créer une identité visuelle **premium, spirituelle, mystérieuse et contemporaine** basée exclusivement sur une palette **noir profond, blanc et rouge**.

L'objectif est de créer une atmosphère à la fois :

* puissante
* mystique
* élégante
* sobre
* immersive
* raffinée
* contemporaine
* africaine sans tomber dans les clichés

### Palette de couleurs

#### Noir profond — couleur dominante

Utiliser un noir presque absolu comme couleur principale :

* `#050505`
* `#0A0A0A`
* `#111111`

Le noir doit constituer l'essentiel des arrière-plans et créer une atmosphère profonde et cinématographique.

#### Blanc — contraste et lisibilité

Utiliser :

* `#FFFFFF`
* `#F5F5F5`
* `#E8E8E8`

Le blanc sert principalement pour :

* les titres
* les textes importants
* les cartes claires lorsque nécessaire
* les éléments de navigation
* les contrastes visuels

#### Rouge — couleur d'accent

Utiliser un rouge profond et sophistiqué :

* `#8B0000`
* `#B00020`
* `#C1121F`

Le rouge doit être utilisé avec parcimonie pour :

* boutons CTA
* liens importants
* états hover
* icônes
* lignes décoratives
* halos lumineux
* éléments graphiques
* badges
* détails du logo
* certains mots-clés dans les titres

Éviter d'utiliser du rouge vif partout.

### Règle importante

**Ne pas utiliser de couleur or, dorée, jaune ou bronze dans l'interface.**

L'identité visuelle doit être construite uniquement autour du :

**NOIR + BLANC + ROUGE**

Utiliser :

* fonds noirs profonds
* dégradés noir → rouge très subtils

* lumière rouge cinématographique

## Cartes

Les cartes de services et produits doivent utiliser :

* fond `#0D0D0D`
* bordure très fine `rgba(255,255,255,0.08)`
* texte blanc
* texte secondaire gris clair
* accents rouges

Au survol :

* légère montée de la carte
* bordure rouge subtile
* glow rouge très léger
* transition de 300 à 500 ms

Éviter les gros effets lumineux.

Le bouton WhatsApp doit rester identifiable malgré la palette noire/blanche/rouge.

Créer un cercle flottant avec une icône WhatsApp claire.

Ajouter autour un très léger halo rouge afin de l'intégrer à l'identité du site.

Animation :

* pulse très subtil
* hover scale `1.05`
* tooltip animé

Texte :

**« Besoin d'une consultation ? Écrivez-nous »**

Le bouton doit être immédiatement visible mais ne doit pas casser l'esthétique premium du site.

## Animations

Les animations doivent utiliser principalement :

* opacity
* transform
* scale
* blur
* translateY
* clip-path
* gradients

Les transitions doivent être lentes, fluides et cinématographiques.

Exemples :

* apparition du rouge dans certains éléments
* halo rouge qui respire lentement
* lignes rouges qui se dessinent
* titres qui apparaissent progressivement
* cartes qui montent légèrement au scroll
* images avec parallax subtil

Ne jamais utiliser d'animations flashy.

## Identité globale

Le résultat doit évoquer :

**« Mystère + puissance + sagesse + élégance »**

et non :

**« site ésotérique chargé de symboles »**.

Le rouge doit représenter visuellement **l'énergie, la force et la présence**, tandis que le noir apporte la profondeur et le mystère et que le blanc apporte la clarté et la confiance.

L'ensemble doit ressembler à une **marque spirituelle premium africaine contemporaine**, avec une identité visuelle forte et immédiatement reconnaissable.

# 13. Intégration Resend

Le formulaire de contact doit envoyer les données par email à l'administrateur via **Resend**.

Important :

Ne jamais exposer la clé API Resend dans le frontend.

Utiliser une architecture backend / serverless adaptée à l'environnement choisi.

Prévoir des variables d'environnement :

`RESEND_API_KEY`

`ADMIN_EMAIL`

`FROM_EMAIL`

Créer une API / fonction serveur :

`POST /api/contact`

Le frontend React envoie les données à cette API.

L'API doit :

1. valider les données
2. nettoyer les entrées
3. vérifier les champs obligatoires
4. envoyer l'email via Resend
5. retourner une réponse JSON propre
6. gérer les erreurs

Prévoir également une protection basique contre le spam.
